의사결정 타임라인 (Decision Timeline)

불확실성

새 항목은 어디에 놓여야 하며 다시 유용해질 수 있는가?

뉴스와 논문 자동 수집, 개인 생각, 영상 링크가 신뢰할 수 있는 재사용 경로 없이 데이터 홍수를 만들었습니다.

탐색

경계가 명확한 inbox에서 수집 실행

항목을 분류하고 목적지를 제안하며 이후 검색에 충분한 맥락을 보존하는 주기적 에이전트 수집을 검증했습니다.

근거

구조화된 배치가 검색을 실용적으로 만들었다

운영 시스템은 탐색용 원문 자료를 찾아주고 업무 자동화 도구를 만들 때 필요한 맥락을 제공합니다.

결정

기획 맥락을 일급 산출물로 취급

마스터 Markdown 문서를 기획 SSOT로 사용하고 맥락이 부족하면 에이전트가 저를 인터뷰하도록 요구합니다.

통합

에이전트 구현에 사람 검토 게이트 적용

PR 검토, 명시적인 사람 소유 점검, 재사용 가능한 구현 skill, 검증된 merge로 생성 작업의 일관성을 유지합니다.

검증된 결과 (Verified Outcome)

동작하는 개인 지식 루프

시스템은 개인 연구와 자동화 작업을 위해 자료를 지속적으로 수집, 정리, 검색합니다. 운영 중이지만 장기 재사용 효과는 계속 관찰하고 있습니다.

책임 경계 (Responsibility boundary)

사람이 소유하는 영역 (Human-owned)

문제, 정보 모델, 목적지 로직, 요구사항 맥락, 아키텍처, 수용 기준, 검토 항목, 최종 merge 결정을 정의합니다.

AI 지원 영역 (AI-assisted)

에이전트는 제가 제공한 규칙 안에서 UI, 데이터 구조, binding, 반복 구현, 문서 갱신, 수집 제안을 가속합니다.

내가 내린 결정 (My Decisions)

  • 수집에서 재사용까지의 문제와 워크플로를 정의했습니다.
  • 기획 SSOT와 맥락 인터뷰 규칙을 수립했습니다.
  • PR 검토와 사람 소유 수용 게이트를 정의했습니다.
  • 에이전트가 구현할 수 있는 방식을 설계했습니다.

팀 결과 (Team Result)

  • AI 에이전트와 함께 제가 구축하고 운영하는 개인 시스템입니다.
  • 워크플로는 연구와 도구 개발에 재사용 가능한 맥락을 제공합니다.
  • 여러 자동화 작성자 ID가 사람 팀의 기여를 의미하지는 않습니다.

현재 상태 (Current Status)

운영 중인 개인 인프라입니다. 수집 루프는 동작하지만 장기 지식 재사용, 유지보수 비용, 생산성을 방어 가능한 수준으로 비교할 만큼 오래 운영되지는 않았습니다.
