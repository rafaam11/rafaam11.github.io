LLM Wiki — AI 기반 개인 지식 시스템

TypeScript Python PostgreSQL Docker LLM Agent MCP

Overview

흩어진 개인 지식을 AI가 인제스트(ingest)·연결(connect)·발행(publish)하는 LLM 기반 지식 시스템을 직접 설계·개발한 개인 프로젝트다. 입력(Notion Inbox) → AI 정제·연결 → 정적 wiki·블로그 발행으로 이어지는 파이프라인을 구축해, 정보가 쌓이기만 하던 기존 PKM의 한계를 넘어 AI가 읽고 연결할 수 있는 형태의 지식으로 자동 정제한다.

AI 코딩 에이전트(Claude Code)를 직접 구성해 커스텀 Skill·슬래시 커맨드로 반복 워크플로를 자동화하고, MCP 서버로 Notion 등 외부 도구를 연동하며, 원칙·컨텍스트 문서(CLAUDE.md)로 일관·재현성을 확보하는 계획 우선·검증 루프 방식을 적용했다.

Approach

Ingest

휘발성 캡처(Keep) → 주간 결산 → Notion Inbox로 모인 메모를 정해진 경로로 수집한다.

Connect

AI가 자동 수집분을 정제·연결하고, 합성 게이트(문헌 스캔 → 승격 제안)를 거쳐 정적 지식(ROM)으로 만든다.

Publish

정제된 지식을 wiki·블로그·모바일 소비 형태로 발행하는 출력 흐름을 자동화한다.
