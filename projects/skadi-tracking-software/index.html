SKADI 데스크톱 앱·API

마커 정의·파일 작업과 실시간 6DoF 상태를 한 데스크톱 앱에서 다루고, DtSkadi.dll API를 의료 수술내비게이션과 로봇 추적 응용에 연결합니다.

광학·하드웨어 설계자와 응용 개발자 사이에서 SDK 버전·빌드·추적 좌표 전달을 맞추고 설치·사용 안내와 원격 지원을 맡았습니다. 반복 종료 문제는 재현 경로·조치·잔여 이슈를 구분해 기록했습니다.

공개 자료는 제품 인터페이스와 통합 경계만 다룹니다. 얼굴, 장치 ID, 좌표값, 로고, 버전, 라이선스 경로와 성능 평가는 제외했습니다. 특정 오류 분기 개선은 모든 장시간 종료 문제의 해소를 뜻하지 않으며, API 유지보수·응용 통합과 원천 API 전체의 개발 소유권을 구분합니다.
