Unity HoloLens 2 MRTK Optical Tracker Registration

Overview

HoloLens 2로 가상 수술 기구·계획을 실제 수술 공간에 정확히 겹쳐 보여주는 혼합현실 Applicator를 전반 주도 개발(기여 95%)해 5개월 내 PoC를 완성했다.

한국전기연구원(KERI) 의뢰 개발용역. 광학 추적 시스템이 실측한 기구 위치를 실시간으로 HoloLens 좌표계에 등록하여, 의사가 실제 환자 신체와 가상 계획(디지털트윈)을 동시에 볼 수 있게 한다.

Problem

영상유도 수술에서 의사는 2D 의료영상과 실제 3D 술야를 머릿속으로 정합해야 해 인지 부하와 오차가 따른다. 수술도구의 현재 위치와 수술 계획을 실제 환자 위에 3D로 겹쳐 실시간으로 보여주는 혼합현실 가이던스가 있으면 직관성과 정확성을 높일 수 있다.

Approach

CT 세그멘테이션 3D 모델(가상 환자)과 스테레오비전 트래커로 측정한 마커·수술도구·환자마커의 위치 관계를 다중 좌표계 정합(4×4 강체변환)으로 합성해, CT 좌표계 기준 수술도구의 실시간 포즈를 산출한다. 이를 실제와 동일한 환자 디지털트윈 위에 표현하고 HoloLens로 가시화하는 파이프라인이다.

Result

  • 광학 추적 기구 위치를 HoloLens 좌표계에 실시간 등록해 가상 수술도구를 환자 위에 오버레이하는 MR 파이프라인 구현
  • 발주처(KERI) 대상 5개월 내 PoC 완성·납품
  • 실제·가상 환자(디지털트윈)와 추적 도구를 동시 표시하는 영상유도 컨셉 검증
