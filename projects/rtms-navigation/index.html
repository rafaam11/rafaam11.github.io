Surgical Navigation 3D Slicer Image Registration rTMS

Overview

반복 경두개자기자극(rTMS) 치료 시 뇌 내 정확한 타깃 지점을 실시간으로 안내하는 내비게이션 시스템(SW)을 주도 개발한 과제. 계명대학교 동산병원 주관, AT&C 공동.

뇌졸중 후 장애 개선 및 뇌가소성 촉진을 목적으로, 환자별 뇌 영상에서 정의한 자극 타깃을 등록(정합)하고, 시술 중 코일 위치·자세를 타깃에 맞추도록 가이드하는 내비게이션 통합시스템과 치료 프로토콜을 개발한다.

Problem

rTMS는 두피 위에서 자기 코일로 특정 뇌 영역을 자극하지만, 타깃 위치를 정확히 안내하는 수단이 없으면 시술자 경험에 의존하게 되어 반복 시술 간 재현성과 정밀도가 떨어진다. 환자마다 뇌 해부 구조가 달라 동일한 외부 좌표가 같은 뇌 영역을 가리키지 않으므로, 환자별 영상에 기반한 개인화된 타깃팅과 실시간 코일 가이드가 필요했다.

Approach

① 타깃 정의

환자 뇌 영상(MRI 등)에서 자극할 타깃 지점을 정의하고, 3D Slicer 기반 도구로 시각화한다.

② 환자 정합(Registration)

영상 좌표계와 실제 환자·추적 장비 좌표계를 정합해, 영상에서 정의한 타깃을 실제 공간에 대응시킨다.

③ 실시간 내비 가이드

추적된 코일의 위치·자세를 타깃 기준으로 실시간 표시해, 시술자가 정확한 지점·각도로 코일을 정렬하도록 안내한다.

Result

  • 3D Slicer 기반 내비게이션 시스템을 주도 개발 — 타깃 시각화 + 실시간 코일 가이드 구현
  • 환자별 영상 기반 타깃팅으로 시술의 재현성·정밀도 향상을 지향
  • 현재 진행 중 과제 — 임상 적용·치료 프로토콜 검증 단계 (정량 지표는 과제 종료 후 갱신 예정)
