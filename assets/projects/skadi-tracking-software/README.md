# SKADI Desktop App and API Evidence

This directory publishes five approved PNG derivatives: two desktop-app screens, two medical-integration screens, and one industrial robot-tracking field screen. The public evidence register is the source of truth for their IDs and paths.

Every asset is metadata-stripped. Crops and masks exclude faces, identifying marks, licence paths, device IDs, coordinate values, logos, and versions; original manuals, decks, and recordings remain outside Git.
