## 핵심 요약 (Summary)

- **석사 포함 약 5년**의 로봇 SW·시뮬레이션 경력. 의료(정밀 트래킹)→산업(무인지게차 자율화)으로 **센서·시뮬레이션·자율시스템 코어 역량**을 심화해 왔습니다.
- **디지털트윈·실시간 시뮬레이션:** NVIDIA **Isaac Sim** 기반 디지털트윈을 2개 도메인(방사능 제염 로봇 훈련 / 무인지게차)에서 구축, **ROS2**·실제 제어망과 연동한 **sim-to-real** 검증 경험.
- **실시간 제어·통신 SW:** **C++23**로 30ms 결정적 제어 루프와 **Zenoh 브로커리스 Pub/Sub**(ROS2 스타일) 분산 통신, **BehaviorTree** 임무계획, Fail-Safe를 직접 설계·양산.
- **센서융합·비전:** ToF+RGB(Basler) **센서 융합 → 3D 점군 → 딥러닝 6-DOF 포즈 추정**, 카메라 캘리브레이션·3D 정합(ICP·PCA·CLPSO) **통합오차 0.2mm**, Foundation Model(SAM3·DUSt3R) 합성/자동 라벨 파이프라인.
- **인터페이스 설계(ICD):** 분산 통신 **메시지 정의**와 **TCP/IP 바이너리 패킷 프로토콜(STX/Len/Tag/Checksum/ETX)**, HW 인터페이스(CAN·UDP·DIO) 설계·구현.
- **가시화:** Unity 기반 XR(HoloLens·Meta Quest·Galaxy XR·MRTK) 수술 내비게이션 인터랙션 구현.
- 성과: **SCI(e) 1편(IF 4.2, Q1)** · 국제학회 1 · **특허 7건** · **수상 9건**. 영어 Intermediate(영문 논문·국제학회 발표), JLPT N2.
