## 0. 요약 프로필

로봇 SW·시뮬레이션 엔지니어로서, **무인체계의 인식–실시간 제어–디지털트윈을 하나의 통신 구조로 통합**해 본 경험이 있습니다. 산업용 무인지게차(AGV)에서 ToF+RGB 센서 융합 인식, C++23·Zenoh 기반 30ms 실시간 제어, Isaac Sim 디지털트윈을 **동일한 메시지 통신으로 연동**해 시뮬레이터에서 검증한 동작을 실기에 적용(sim-to-real)하고 현장 양산까지 수행했습니다. 또한 의료 분야에서 스테레오 비전 광학 트래킹(통합오차 0.2mm)과 **바이너리 패킷 프로토콜(ICD)** 설계, Unity 기반 XR 가시화를 담당했습니다.

이는 한화시스템 "무인 디지털트윈" 직무가 요구하는 **센서·통신 가상화, 실시간 시뮬레이션 환경 구축, 시뮬레이터-실선 연동(HILS), 가시화, 합성데이터, 운항 데이터 실시간 동기화**와 구조적으로 동일합니다. 도메인은 의료·산업이었지만, **쌓아온 코어 역량(센서·시뮬레이션·자율시스템 SW)은 해양 무인체계 디지털트윈에 그대로 전이**됩니다.

## 2. 핵심 프로젝트 (STAR)

### P1. 무인지게차(AGV) 자율운반 디지털트윈 시스템 ★
**[직무 연관성] 실시간 시뮬레이션 구축 · 센서/통신 가상화 · 자율운항 검증 · HILS · 운항 데이터 동기화 · ICD · SW 통합 — 본 직무와 가장 직접적으로 대응**

- **S (상황):** 산업 현장의 지게차를 무인 자율 운반으로 전환하는 과제. 인식·실시간 제어·검증이 분리되면 통합 단계 비용이 급증하고, 실기 시험은 비용·위험이 크다.
- **T (과제):** ① 다양한 위치·각도의 적재 대상을 빠르고 정확히 인식, ② 안전을 위한 결정적(deterministic) 실시간 제어, ③ 시뮬레이션에서 미리 검증해 실기 적용 위험을 낮추는 통합 구조 확보.
- **A (행동):**
  - **인식:** ToF+RGB(Basler) **센서 융합 → 3D 점군 → 딥러닝 6-DOF 포즈(x·y·z·yaw·roll)** 추정. 초기 정렬·정밀 정렬 2단계 구조 설계(정밀 정렬은 경량 모델 실시간). Foundation Model(SAM3) 분할을 파이프라인에 통합.
  - **실시간 제어:** **C++23**로 30ms 결정적 제어 루프, **Zenoh 브로커리스 Pub/Sub**(ROS2 스타일) 분산 통신, 계층형 아키텍처(Service→Communication→Control→Hardware), **BehaviorTree** 임무계획, HAL(CAN·UDP·DIO), 장애 시 즉시 안전 정지(Fail-Safe), 텔레메트리(InfluxDB).
  - **디지털트윈:** **Isaac Sim** 디지털트윈을 실제 제어망과 **동일한 메시지 통신**으로 연동 → 시뮬레이터에서 인식·제어를 검증한 뒤 실기에 적용(sim-to-real).
  - **인터페이스:** 분산 통신 메시지 정의(ICD)와 모듈 간 시퀀스 설계.
  - **현장:** 고객 현장 설치·캘리브레이션·시운전·안정화 및 양산 적용.
- **R (성과):** 초기 정렬 인식 약 **500–700ms** 달성, Foundation Model·커스텀 학습 통합으로 직접 어노테이션 대비 **1개월+ 개발기간·비용 절감**, 인식–제어–디지털트윈 단일 통신 통합으로 **시뮬레이터–실기 검증 루프** 확보, 현장 양산.
- **기술스택:** C++23, Zenoh, BehaviorTree, Eigen·OSQP, ToF+RGB Fusion, Open3D·OpenCV·OpenVINO·VTK, SAM3, Isaac Sim, Qt, CMake·Conan, InfluxDB.

### P2. 방사능 오염 시설 정화 디지털트윈 훈련 시뮬레이터 (KAERI·ANL)
**[직무 연관성] 디지털트윈·실시간 시뮬레이션 환경 구축 · 물리엔진·동역학 · ROS2 연동**

- **S:** 방사성 오염 환경은 인간 작업자가 직접 훈련하기 어렵다. 로봇 제염 작업 훈련용 디지털트윈이 필요.
- **T:** 실제 시설과 동일한 가상 환경을 구축하고, 실제 로봇 제어 SW와 연동되는 훈련 시뮬레이터 개발. 방사성 환경 특유의 가시성 저하·조작 제약 반영.
- **A:** NVIDIA **Isaac Sim** 위에 시설 디지털트윈 구축, **ROS2**로 로봇 제어 SW 연동, 훈련 시나리오 설계. 산업통상자원부 과제, 한국원자력연구원(KAERI) 주관·미국 아르곤국립연구소(ANL) 공동.
- **R:** Isaac Sim 기반 로봇 제염 훈련 환경 구축(기여 약 70%), 물리·동역학 기반 시뮬레이션과 ROS2 토픽 연동 검증.
- **기술스택:** Isaac Sim, Isaac Lab, ROS2, Python, Linux, Docker.

### P3. 고정밀 수술 내비게이션 & 광학 트래킹 (NeuroPilot / SMCNavi)
**[직무 연관성] 센서 모델링·캘리브레이션 · 3D 정합 정밀도 · ICD(바이너리 프로토콜) 설계 · AI 인식 · SW 통합**

- **S:** 수술 내비게이션은 mm 단위 정밀도와 실시간 추적·통신이 요구된다.
- **T:** 스테레오 비전 광학 트래킹과 영상 좌표계 정합, 트래킹 장비–내비게이션 SW 간 실시간 인터페이스 설계.
- **A:** 스테레오 카메라 기반 광학 트래킹, **3D 좌표계 정합(ICP·PCA·CLPSO)**, 카메라 캘리브레이션(intrinsic/extrinsic). 3D Slicer 기반 뉴로내비게이션에 **TCP/IP 바이너리 패킷 프로토콜(STX/Len/Tag/Data/Checksum/ETX)** 설계로 트래킹 서버와 실시간 통신, AI segmentation으로 치료 타깃 자동 탐색. 정부·병원 과제(삼성서울병원 가상병원과제 등) 3년+ 수행.
- **R:** 좌표계 정합 **통합오차 약 0.2mm** 달성, 실시간 패킷 통신 구조 확립, 관련 특허 출원(좌표계 정합 방법·위치 추적 장치·스테레오 카메라 구동 등).
- **기술스택:** Stereo Vision, OpenCV·Open3D, ICP/PCA/CLPSO, 3D Slicer, TCP/IP 바이너리 프로토콜, Python, C++, C#(마커 에디터).

### P4. 혼합현실(XR) 수술 내비게이션 가시화
**[직무 연관성] Unity 기반 가시화 · 3D 공간 인터랙션 · 실시간 연동 (공고 명시 요건)**

- **S:** 영상유도 수술에서 3D 해부구조와 도구를 직관적으로 가시화할 필요.
- **T:** Unity 기반 혼합현실 환경에서 광학 트래킹·영상 정합 결과를 실시간 가시화·인터랙션.
- **A:** **Unity·HoloLens·Meta Quest·Galaxy XR·MRTK**로 수술 내비게이션 XR 인터페이스 구현, Optical Tracker·Registration 연동, 멀티플레이어 XR(PUN2)·FastAPI 백엔드(Life Careverse).
- **R:** 다수 과제에서 XR 수술 내비게이션·케어 플랫폼 구현·실증(일부 기여 95~100%), 의료메타버스학회 우수포스터상(2024).

## 4. 갭 & 학습 계획

해양/방산 도메인, MATLAB/Simulink 심화, 강화학습 기반 자율운항은 직접 경험이 제한적입니다. 그러나 **센서 모델링·실시간 시뮬레이션·sim-to-real 검증·ICD 설계라는 직무의 본질 역량을 이미 보유**하고 있어, 해양 도메인 지식(선박 6-DOF 운동·COLREG·해상환경 모델)과 도구(Simulink, RL 훈련환경)는 빠르게 흡수 가능합니다. 입사 초기에는 강점 영역(센서·시뮬레이션 통합·가시화·실시간 SW)에서 즉시 기여하며 해양 도메인을 병행 학습하겠습니다.

## 5. 지원 동기 / 자기소개

저는 의료(정밀 트래킹)에서 산업(무인지게차 자율화·디지털트윈)으로, **센서·시뮬레이션·자율시스템이라는 하나의 코어 역량을 디지털트윈으로 심화**해 왔습니다. 다음 단계로, 그 역량을 **국가 안보와 직결되는 가장 도전적인 무인체계 — 해양**에 적용하고자 합니다.
