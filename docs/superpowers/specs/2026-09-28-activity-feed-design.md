# Activity Feed Design

> 2026-09-28 · owner-approved. Extends the News page with activity photos and career chapters. Amends the "identifiable people" rule of `2026-08-21-scholar-portfolio-design.md` for News activity photos only.

## Goal

Use the owner's private activity media (`assets/usermedia/`, 592 MB, git-ignored) to show the career path — invention club and robot building at Kumoh, undergraduate research, DGIST, DIGITRACK — not only projects.

## Decisions

| Topic | Decision |
|---|---|
| Scope | Research, career, outside activities, overseas programmes and club social events |
| People in photos | Published as-is (owner decision). Names of other people never appear in captions, alt text or bodies. On request, blur or remove the derivative |
| Originals | `assets/usermedia/` is git-ignored and read-only for tooling |
| SSOT | `data/activity-media.json`; `js/local-media-data.js` is generated by `scripts/profile-home.cjs` with public fields only (`id, type, path, poster, width, height, eventIds, order, translations`) and approved records only |
| M-ids | Frozen: 1-based position in the code-point-sorted usermedia listing at first catalog, checked by `sourceSha256`; new files get M218+ |
| Images | WEBP, long edge 1280 (test cap 1600), ≤300 KB, metadata stripped; tiled HEIC decoded to PNG first |
| Video | H.264 ≤720p, ≤30 s, ≤4 MB, no audio by default, poster at 1 s, at most five |
| Budget | `assets/local-review/` ≤16 MiB (10.3 MiB at 71 records) |
| Evidence | CV facts cite `data/public-cv.json`; photo-only events cite `{ path: 'data/activity-media.json', locator: 'M###' }` and the record must list the event |
| Category | New `activity` (대외활동 / Activities); extra categories live in `labels[id][3]` |
| Chapters | DIGITRACK (2023-02–) · DGIST M.S. (2021-03–) · Kumoh (–2021-02); year-precision dates fall into the earlier chapter; `dgist-masters-degree-2023` overrides to DGIST |
| Media per event | Three photos and one video visible; further photos fold into `<details>`; images carry width/height |
| Home | Selected activities: quadruped robot (2020), ISM 2019, ACCAS 2022 |

## Pipeline

`scripts/activity-media.cjs` — `catalog` (ids, sha256, dates from EXIF/filename) → `sheet` (labelled contact sheets for owner review under `.superpowers/review/`) → `derive` (draft records with TODO captions) → captions and links in the JSON → `node scripts/public-cv-summary.cjs --write` → `check`.

## Tests

`tests/activity-media.test.cjs` (ignore rule, caption hygiene, SSOT, budget, evidence), `tests/activity-media-pipeline.test.cjs` (parsers, ffmpeg arguments, write guard), `tests/activity-feed.test.cjs` (chapters, filters, folded media, Home selection).
