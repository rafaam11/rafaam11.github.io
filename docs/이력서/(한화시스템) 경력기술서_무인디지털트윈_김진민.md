## 0. 요약 프로필

**디지털트윈/시뮬레이터를 의료·산업 2개 도메인에서 구축**해 온 로봇 SW·시뮬레이션 엔지니어입니다. 의료에서는 자사(디지트랙) **스테레오비전 마커추적·다중 좌표계 정합으로 CT 좌표계 기준 수술도구를 실시간 추적**하고 **HoloLens로 실제 환자 옆에 가상환자(환자 디지털트윈)를 띄워** 추적 중인 도구·수술계획 가이드를 가시화하는 수술 내비게이션을, 산업에서는 무인지게차(AGV)의 인식·실시간 제어를 **Isaac Sim 디지털트윈과 동일 통신으로 연동해 시뮬레이터에서 검증한 동작을 실기에 적용(sim-to-real 검증 루프)**하고 현장 양산까지 수행했습니다. 두 도메인 모두 **센서 가상화·실시간 정합·인터페이스(ICD)·실시간 가시화**를 직접 설계했고, 가시화·도구 개발은 **Unity·C# 응용 SW**로 구현했습니다.

이는 한화시스템 "무인 디지털트윈" 직무가 요구하는 **센서·통신 가상화, 실시간 시뮬레이션 환경 구축, 시뮬레이터-실선 연동(HILS), Unity 가시화, 합성데이터, 운항 데이터 실시간 동기화**와 구조적으로 동일합니다. 도메인은 의료·산업이었지만 **쌓아온 코어 역량(센서·시뮬레이션·자율시스템 SW)은 해양 무인체계 디지털트윈에 그대로 전이**됩니다.

## 2. 핵심 프로젝트 (STAR)

### P1. 무인지게차(AGV) 자율운반 디지털트윈 시스템 ★
**[직무 연관성] 실시간 시뮬레이션 구축 · 센서/통신 가상화 · 자율운항 검증 · 시뮬레이터-실선 연동(sim-to-real) · 운항 데이터 동기화 · ICD · SW 통합 — 본 직무와 가장 직접적으로 대응**

- **S (상황):** 산업 현장의 지게차를 무인 자율 운반으로 전환하는 과제. 인식·실시간 제어·검증이 분리되면 통합 비용이 급증하고, 실기 시험은 비용·위험이 크다.
- **T (과제):** ① 다양한 위치·각도의 적재 대상을 빠르고 정확히 인식, ② 안전을 위한 결정적(deterministic) 실시간 제어, ③ 시뮬레이션에서 미리 검증해 실기 적용 위험을 낮추는 통합 구조 확보.
- **A (행동):**
  - **인식:** ToF+RGB(Basler) **센서 융합 → 3D 점군 → 딥러닝 6-DOF 포즈(x·y·z·yaw·roll)** 추정. 초기 정렬·정밀 정렬 2단계 구조 설계(정밀 정렬은 경량 모델 실시간). Foundation Model(SAM3) 분할을 파이프라인에 통합.
  - **실시간 제어:** **C++23**로 30ms 결정적 제어 루프, **Zenoh 브로커리스 Pub/Sub**(ROS2 스타일) 분산 통신, 계층형 아키텍처(Service→Communication→Control→Hardware), **BehaviorTree** 임무계획, HAL(CAN·UDP·DIO), 장애 시 즉시 안전 정지(Fail-Safe), 텔레메트리(InfluxDB).
  - **디지털트윈·sim-to-real:** **Isaac Sim** 디지털트윈을 실제 제어망과 **동일한 메시지 통신**으로 연동 → 시뮬레이터에서 인식·제어를 검증한 뒤 실기에 적용하는 **sim-to-real 검증 루프**(제어SW-in-the-loop 성격) 구성.
  - **인터페이스:** 분산 통신 메시지 정의(ICD)와 모듈 간 시퀀스 설계.
  - **현장:** 고객 현장 설치·캘리브레이션·시운전·안정화 및 양산 적용.
- **R (성과):** 초기 정렬 인식 약 **500–700ms** 달성, Foundation Model·커스텀 학습 통합으로 직접 어노테이션 대비 **1개월+ 개발기간·비용 절감**, 인식–제어–디지털트윈 단일 통신 통합으로 **시뮬레이터–실기 검증 루프** 확보, 현장 양산.
- **기술스택:** C++23, Zenoh, BehaviorTree, Eigen·OSQP, ToF+RGB Fusion, Open3D·OpenCV·OpenVINO·VTK, SAM3, Isaac Sim, Qt, CMake·Conan, InfluxDB.

### P2. 의료 수술 내비게이션 — 환자 디지털트윈 (구강악안면외과 중심) ★
**[직무 연관성] 센서 기반 위치추적 · 다중 좌표계 실시간 정합 · 디지털트윈 동기화 · MR/AR 가시화 — 해양 무인 디지털트윈과 구조적으로 동일**

- **S (상황):** 구강악안면외과 수술에는 CT 기반 환자 3D 모델(세그멘테이션)은 있으나, 수술 중 실제 환자·수술도구의 위치를 그 CT(가상) 좌표계 위에서 실시간으로 알 수 없다. 신경 등 보이지 않는 구조를 피하고 계획된 가이드를 보며 수술할 방법이 필요하다.
- **T (과제):** 수술 공간에 산재한 좌표계들을 통합 계산해 **CT 좌표계 기준 수술도구를 실시간 추적**하고, 이를 실제와 동일한 **환자 디지털트윈** 위에 표현·가시화한다.
- **A (행동):**
  - **센서 위치추적:** 자사(디지트랙) **스테레오비전 기반 마커 위치추적**으로 마커·트래커·수술도구의 3D 위치를 실시간 측정.
  - **다중 좌표계 정합:** 마커↔트래커(4×4 강체변환), 트래커↔수술도구, 환자↔환자마커 관계를 정립·합성하여 **CT(가상 트윈) 좌표계에서 수술도구의 실시간 포즈**를 산출 (= 수술 내비게이션 코어).
  - **환자 디지털트윈:** 실제 세계와 동일한 트윈 환자(CT 세그멘테이션 3D 모델) 위에 추적된 수술도구를 실시간 표현 → 실세계–가상세계 동기화.
  - **MR/AR 가시화:** **HoloLens**로 실제 환자 옆에 **가상환자 홀로그램**을 정합 표시하고, 추적 중인 수술도구가 가상 환자에서도 보이도록 구현 → **보이지 않는 구조(예: 신경) 회피**와 **수술계획 단계의 가상 가이드 오버레이**를 지원(상세 Unity/C# 구현은 P4).
- **R (성과):** CT 좌표계 기준 **실시간 수술도구 추적**과 **AR 환자 디지털트윈 내비게이션**을 구현 — 술자가 보이지 않는 해부구조·계획 가이드를 실시간으로 확인하며 수술 가능. 관련 특허 출원(좌표계 정합 방법·위치 추적 장치·2축 스테레오 카메라 구동 등).
- **확장 (현재진행형):** 동일한 좌표계 정합·트래킹·디지털트윈 코어를 **정형외과(뼈 위치 탐지)·재활의학과(rTMS 코일 위치 추적)·방사선종양학과(환자 피부조직 디지털 구현·상태 파악)** 로 발전 중.
- **기술스택:** Stereo-Vision Marker Tracking, 강체변환·다중 좌표계 정합(4×4), CT 세그멘테이션 3D 모델, HoloLens·MR·Unity·C#.

### P3. 방사능 오염 시설 정화 디지털트윈 훈련 시뮬레이터 (KAERI·ANL)
**[직무 연관성] 디지털트윈·실시간 시뮬레이션 환경 구축 · 시뮬레이터 기반 SW 검증 · 물리/동역학 · ROS2 연동**

- **S:** 방사성 오염 환경은 인간 작업자가 직접 훈련하기 어렵다. 로봇 제염 작업 훈련용 디지털트윈이 필요.
- **T:** 실제 시설과 동일한 가상 환경을 구축하고, 실제 로봇 제어 SW와 연동되는 훈련 시뮬레이터 개발. 방사성 환경 특유의 가시성 저하·조작 제약 반영.
- **A:** NVIDIA **Isaac Sim** 위에 시설 디지털트윈 구축, **ROS2**로 로봇 제어 SW 연동, 훈련 시나리오 설계. 산업통상자원부 과제, 한국원자력연구원(KAERI) 주관·미국 아르곤국립연구소(ANL) 공동.
- **R:** Isaac Sim 기반 로봇 제염 훈련 환경 구축(기여 약 70%), 물리·동역학 기반 시뮬레이션과 ROS2 토픽 연동 검증.
